# 宣讲会报名、图书借阅与导出提示设计

## 范围

- 将现有 `/lecture-signups` 占位页替换为宣讲会报名名单。
- 将现有 `/book-borrows` 占位页替换为图书借阅记录。
- 为招新管理二面导出按钮增加悬停提示。

## 宣讲会报名

- 卡片标题为“宣讲会报名名单”，显示 `10 / 50`，含义为报名人数/名额。
- 表格列：序号、姓名、学号、专业、联系电话、报名时间。
- 右上角“导出名单”下载当前名单的 UTF-8 CSV 文件。
- 后端尚无正式接口，前端暂定 `GET /qt/activity/lecture/registrations`，Mock 返回 `rows`、`total`、`quota`。
- 导出由前端基于当前列表生成，不新增后端导出契约。

## 图书借阅

- 使用已记录接口 `GET /system/borrow/detailList`，不传 `userId`，展示管理端全部借阅记录。
- 表格列：借阅人、书籍编号、书名、类型、借阅日期、应还日期、实际归还、状态。
- 状态：借阅中、已逾期、已归还；逾期行使用浅红背景。
- 页面只读，不增加借书、还书或审核操作。

## 路由与权限

- 继续使用动态路由和既有权限 `signup:list`、`borrow:list`。
- 不改变已确认的角色菜单规则；后端路由未下发时仍不可访问页面。

## 招新导出提示

- 二面导出按钮外包 Element Plus Tooltip。
- 鼠标悬停显示“导出的内容是当前页面筛选结果”。
- 原有权限、导出行为和按钮样式保持不变。

## 验收

- 两个页面在 Mock 模式可完整加载，空态和错误态可重试。
- 宣讲会 CSV 可下载且字段与当前表格一致。
- 图书逾期行、类型与状态样式符合设计稿。
- 二面导出按钮悬停出现指定文案。
- 单元测试、Lint、生产构建和浏览器验收通过。
