# Quanta 业务页面紧凑密度与成员页样式微调规格

日期：2026-08-24  
状态：方案 A 已确认，等待书面规格复核

## 1. 目标

修正成员管理白色内容卡片中文字、控件和操作按钮偏大的问题，并把紧凑密度作为后续宣讲会报名、精英分享会、预约、借阅、订购等业务页面的默认视觉规范。

本次仅修改成员管理内容区。左侧导航、顶部标题栏、登录页和控制台不受影响。

## 2. 方案

采用模块局部 CSS 覆盖和组件尺寸参数，不修改 Element Plus 全局变量，不修改公共按钮和状态组件的默认尺寸。这样可以精确还原成员页，并防止已完成页面发生连带变化。

后续业务页面在各自模块中复用同一组紧凑尺度；等多个模块稳定后，再评估是否抽取为公共业务表格样式。

## 3. 成员页面调整

- 内容卡片整体正文和表格文字缩小一级。
- 搜索框与导入按钮采用紧凑高度和较小字号。
- 届次页签缩小高度、水平内边距和字号。
- 表头、数据行和分页区域同步收紧，保持信息层级清晰。
- 删除按钮改为 `#E81F1F` 红底白字。
- 重置密码按钮改为 `#FDAF32` 黄底白字。
- 删除与重置按钮使用相同高度、圆角和紧凑字号。
- 历史届“是否留任”按钮复用重置密码的紧凑实色样式：`#FDAF32` 黄底白字，11px 字号、24px 高度。
- “在职”状态文字改为 `rgb(29, 78, 216)`，保留浅蓝色胶囊背景。
- 历史届其他状态继续使用原语义色，但尺寸同步缩小。
- 不改变筛选、权限、删除确认、重置密码、导入和留任逻辑。

## 4. 后续业务页面密度规范

- 表单标签、输入框、选择器、日期控件、表头与正文默认使用紧凑尺寸。
- 普通业务表格行高应明显低于第一版成员页，但仍保留可点击空间和可读性。
- 行内操作按钮使用小号字体与紧凑内边距；危险、主要、警告操作继续使用清晰的语义色。
- 页面标题、侧栏菜单和顶部栏属于导航层级，不跟随业务内容缩小。
- 弹窗正文和表单随业务密度调整，但弹窗标题仍保持清晰层级。
- 不以浏览器缩放或全局 `font-size` 强制压缩页面，避免影响无障碍和其他模块。

## 5. 验收

- 成员管理内容卡片在 1920×1080 下比当前版本明显紧凑，并接近用户标注图片的密度。
- 删除和重置密码颜色与指定色值一致，文字为白色。
- 历史届“是否留任”计算背景色为 `rgb(253, 175, 50)`，文字为白色。
- “在职”文字计算颜色为 `rgb(29, 78, 216)`。
- 左侧导航和顶部标题栏的计算字号与修改前一致。
- 管理员与只读账号的按钮权限不受影响。
- Lint、自动化测试和生产构建通过，浏览器控制台无错误或警告。
