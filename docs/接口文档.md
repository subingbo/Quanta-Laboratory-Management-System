# 实验室系统（RuoYi-Vue-Qt）前端对接接口文档

> 后端：Spring Boot，端口 `8080`，无 context-path，基础地址 `http://<host>:8080`
> 生成日期：2026-08-24 · 基于 master 分支代码逐接口核对生成
> 更新：2026-08-25 · /login 返回值新增实验室成员扩展字段（见 2.2）

---

## 一、通用约定

### 1.1 统一响应体 AjaxResult

除分页列表外，所有接口返回 JSON 对象，固定包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 状态码。`200` 成功；`500` 失败；`401` 未登录/token 失效；`601` 警告 |
| msg | string | 提示消息（如"操作成功"、错误原因） |
| data | any | 业务数据（仅当有数据时才出现该字段） |
| ...其他键 | - | 部分接口会把业务数据直接平铺在根层级（如 login 的 `token`），以各接口说明为准 |

### 1.2 分页响应体 TableDataInfo

所有 `/list`、`/detailList` 接口返回：

| 字段 | 类型 | 说明 |
|---|---|---|
| total | long | 总记录数 |
| rows | array | 当前页数据，元素结构见各接口"rows 元素字段" |
| code | int | `200` 成功 |
| msg | string | "查询成功" |

**分页/排序通用参数**（Query String，适用于所有 list 接口）：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| orderByColumn | string | 否 | 排序字段（驼峰名，后端转下划线） |
| isAsc | string | 否 | `asc` / `desc` |

### 1.3 认证方式

登录后，除标注 **免登录** 的接口外，均需携带请求头：

```
Authorization: Bearer <login 返回的 token>
```

时间格式统一为 `yyyy-MM-dd HH:mm:ss`（GMT+8）。`Date` 类型字段均按此格式。

### 1.4 免登录接口

`POST /login`、`POST /register`、`GET /captchaImage`、静态资源 `GET /profile/**`

## 二、认证模块

### 2.1 获取验证码

```
GET /captchaImage
```
免登录。

**返回值**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "captchaEnabled": true,      // boolean 验证码开关是否开启
  "uuid": "5b6c9a...",          // string 验证码唯一标识，登录时回传
  "img": "iVBORw0KGgo..."       // string 图片的 Base64 编码，前端直接 data:image/gif;base64,<img> 展示
}
```
> 若 `captchaEnabled = false`，则响应中不含 `uuid` 与 `img`，登录时也不需要传 `code`/`uuid`。

### 2.2 登录

```
POST /login
Content-Type: application/json
```
免登录。

**请求参数**（LoginBody）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| code | string | 条件 | 验证码（验证码开关开启时必填） |
| uuid | string | 条件 | 验证码唯一标识（与 code 配套） |
| loginType | string | 否 | 登录入口身份：`0` 新生 / `1` 塔员。传入时后端会校验账号身份是否匹配；不传则不校验 |

**返回值**（成功）——即用户举例的场景：不只返回 object，实际平铺了 token 和实验室成员（塔员）扩展字段：
```json
{
  "code": 200,
  "msg": "操作成功",
  "token": "eyJhbGciOiJIUzUxMiJ9....",   // string JWT 令牌，后续请求放 Authorization 头
  "isQuantaMember": "0",                  // string 是否是实验室成员(塔员)："1"=是塔员，"0"=新生
  "memberNo": "Q001",                     // string 塔员编号（非塔员为 null）
  "memberDepartment": "BACKEND",          // string 所属部门（BACKEND/PRODUCT/DESIGN/FRONTEND/ANDROID，非塔员为 null）
  "memberTitle": "负责人",                // string 职位/头衔（非塔员为 null）
  "memberCohort": "20th",                 // string 届别/期数（非塔员为 null）
  "studentNo": "20250101",               // string 学号（塔员通常为 null）
  "className": "计算机2301"              // string 班级
}
```
> 扩展字段与 `GET /getInfo` 返回的 `user` 对象中的同名字段一致；登录响应里平铺一份，方便前端免二次请求直接判断身份/展示档案。

**失败示例**（code 非 200）：
```json
{ "code": 500, "msg": "该账号不是塔员，请使用新生入口登录" }
{ "code": 500, "msg": "验证码错误" }
{ "code": 500, "msg": "用户不存在/密码错误" }
```

### 2.5 注册（仅限新生自助注册）

```
POST /register
Content-Type: application/json
```
免登录。

**请求参数**（RegisterBody extends LoginBody）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名（2~20 个字符） |
| password | string | 是 | 密码（5~20 个字符） |
| nickName | string | 否 | 昵称（不传默认用用户名） |
| studentNo | string | 是 | 学号（全局唯一） |
| className | string | 是 | 班级 |
| code | string | 条件 | 验证码（开启验证码时必填） |
| uuid | string | 条件 | 验证码唯一标识 |
| loginType | string | 否 | 若传 `"1"` 或 `"member"` 将被拒绝——塔员账号只能管理员开通 |

**返回值**：
```json
{ "code": 200, "msg": "操作成功" }
// 注册功能未开启或校验失败时：
{ "code": 500, "msg": "学号已存在，请勿重复注册" }
```

## 三、个人信息模块

### 3.1 查询个人信息

```
GET /system/user/profile
```
需登录。

**返回值**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { /* 同 /getInfo 的 user 对象完整解析，此处不再重复；password 不返回 */ },
  "roleGroup": "超级管理员",        // string 所在角色组（多个逗号分隔）
  "postGroup": ""                   // string 所在岗位组（多个逗号分隔）
}
```

### 3.2 修改个人信息

```
PUT /system/user/profile
Content-Type: application/json
```

**请求参数**（SysUser 子集）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nickName | string | 否 | 昵称 |
| phonenumber | string | 否 | 手机号（需全局唯一） |
| email | string | 否 | 邮箱（需全局唯一） |
| sex | string | 否 | 性别："0"男 "1"女 "2"未知 |

**返回值**：`{ "code": 200, "msg": "操作成功" }`；失败如 `{ "code": 500, "msg": "修改用户'xxx'失败，手机号码已存在" }`

### 3.3 修改密码

```
PUT /system/user/profile/updatePwd
Content-Type: application/json
```

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| oldPassword | string | 是 | 旧密码明文 |
| newPassword | string | 是 | 新密码明文（不能与旧密码相同） |

**返回值**：`{ "code": 200, "msg": "操作成功" }`；失败：`"旧密码错误"` / `"新密码不能与旧密码相同"`

### 3.4 上传头像

```
POST /system/user/profile/avatar
Content-Type: multipart/form-data
```

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| avatarfile | file | 是 | 图片文件（form-data 字段名必须是 `avatarfile`） |

**返回值**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "imgUrl": "/profile/avatar/2026/08/24/xxx.png"   // string 头像访问路径（相对路径）
}
```

## 四、通用文件模块

### 4.1 通用上传（单个文件）

```
POST /common/upload
Content-Type: multipart/form-data
```
需登录。

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | file | 是 | 文件 |
| subDir | string | 否 | 子目录，仅允许：`qt/clothing-item`、`qt/payment-qr`、`qt/payment-proof` |

**返回值**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "url": "http://localhost:8080/profile/upload/2026/08/24/xxx.png", // string 完整可访问 URL
  "fileName": "/profile/upload/2026/08/24/xxx.png",                 // string 相对路径（存库用这个）
  "newFileName": "xxx.png",                                         // string 新文件名
  "originalFilename": "原始文件名.png"                              // string 原始文件名
}
```
> C 端上传付款截图即用此接口：`subDir=qt/payment-proof`，然后把返回的 `fileName` 作为订单的 `paymentProofPath` 提交。

### 4.2 通用下载

```
GET /common/download?fileName=<name>&delete=<true|false>
```
需登录。返回文件流（`application/octet-stream`），无 JSON。

## 六、后台管理模块（ruoyi-ui 管理端）

以下接口为标准 CRUD 五件套，权限注解目前已被注释（`@PreAuthorize` 全部注释掉），**任何登录用户均可调用**，前端仍按权限标识渲染按钮即可。

每组的通用形态：

- 列表：`GET /xxx/list` → TableDataInfo（分页，支持实体字段作筛选条件，用法同上文各 detailList）
- 详情：`GET /xxx/{id}` → AjaxResult，`data` 为单个实体（字段解析见第五节对应表格）
- 新增：`POST /xxx` → AjaxResult（JSON body）
- 修改：`PUT /xxx` → AjaxResult（JSON body）
- 删除：`DELETE /xxx/{ids}` → AjaxResult，ids 支持逗号分隔批量，如 `/system/activity/1,2,3`
- 导出：`POST /xxx/export` → 文件流（Excel），非 JSON

| 资源 | 路径前缀 | 主键 | 备注 |
|---|---|---|---|
| 实验室图书 | /system/book | bookId | — |
| 实验室活动 | /system/activity | activityId | 新增时后端自动补 creatorUserId/createBy |
| 活动报名 | /system/signup | signupId | 另有 GET /detailList 联表版 |
| 图书借阅记录 | /system/borrow | borrowId | 另有 GET /detailList 联表版 |
| 实验室工位 | /system/workstation | workstationId | — |
| 工位预约记录 | /system/reservation | reservationId | 另有 GET /detailList 联表版 |
| 服装配置 | /system/item | itemId | 新增/修改为 **multipart/form-data**（字段 effectImageFile 可选传效果图）；DELETE /image/{itemId} 清空效果图 |
| 服装订单 | /system/order | orderId | 另有 GET /detailList 联表版 |
| 固定付款码配置 | /system/payment-config | configId | 新增/修改为 **multipart/form-data**（字段 qrImageFile 可选传二维码图）；DELETE /image/{configId} 清空二维码 |
| 实验室成员 | /qt/member | userId | 只有 list 一个接口，见 5.1.1 |

**multipart 新增/修改的字段约定**：实体字段直接用 form-data 的 key/value（如 `itemName=卫衣`、`colorOptionsJson=["黑","白"]`），文件字段单独传。
