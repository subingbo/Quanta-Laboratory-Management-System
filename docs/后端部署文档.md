# Quanta / RuoYi 后端部署文档

本文只覆盖 **后端**（`ruoyi-admin` + MySQL + Redis + 业务 SQL），不涉及 `ruoyi-ui` / `ruoyi-qt-ui` 前端。

## 1. 环境要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | **17+** | 项目基于 Spring Boot 4.x |
| Maven | 3.8+ | 编译打包 |
| MySQL | 8.0 | 库名默认 `ry-vue` |
| Redis | 7.x（兼容 6+） | 验证码、Token 缓存 |
| 可选 | Docker / Docker Compose | 一键起 MySQL、Redis |

操作系统：Windows / Linux 均可。

## 2. 依赖服务启动（推荐 Docker）

在项目根目录 `RuoYi-Vue-Qt` 执行：

```bash
docker compose up -d
```

默认容器：

| 服务 | 容器名 | 宿主机端口 | 默认账号 |
|------|--------|------------|----------|
| MySQL 8.0 | `ruoyi-mysql` | `3306` | root / `password`，库 `ry-vue` |
| Redis 7 | `ruoyi-redis` | `6379` | 无密码 |

可用环境变量覆盖（见根目录 `docker-compose.yml`）：

- `MYSQL_PORT`、`MYSQL_ROOT_PASSWORD`、`MYSQL_DATABASE`
- `REDIS_PORT`

查看状态：

```bash
docker compose ps
docker compose logs -f mysql
```

> 当前 `docker-compose.yml` **不会**自动导入 SQL，需要按第 3 节手动执行。

若不用 Docker，请自行安装 MySQL 8 与 Redis，并保证本机可连通。

## 3. 初始化数据库

### 3.1 建库

```bash
mysql -uroot -p --default-character-set=utf8mb4 -e "CREATE DATABASE IF NOT EXISTS \`ry-vue\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

Docker MySQL 示例（密码与 compose 默认一致时）：

```bash
mysql -h127.0.0.1 -P3306 -uroot -ppassword --default-character-set=utf8mb4 -e "CREATE DATABASE IF NOT EXISTS \`ry-vue\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 3.2 导入脚本（顺序固定）

在项目根目录执行：

```bash
# 1) RuoYi 基础表 + 管理员账号
mysql -h127.0.0.1 -P3306 -uroot -ppassword --default-character-set=utf8mb4 ry-vue < sql/ry_20260417.sql

# 2) 可选：Quartz 定时任务表
mysql -h127.0.0.1 -P3306 -uroot -ppassword --default-character-set=utf8mb4 ry-vue < sql/quartz.sql

# 3) 实验室业务表结构 + 测试数据（推荐一键）
mysql -h127.0.0.1 -P3306 -uroot -ppassword --default-character-set=utf8mb4 ry-vue < sql/lab/lab_full.sql
```

分步导入实验室模块：

```bash
mysql ... ry-vue < sql/lab/lab_init.sql
mysql ... ry-vue < sql/lab/lab_seed.sql
```

已有旧库仅补字段 / 开注册：

```bash
mysql ... ry-vue < sql/lab/lab_patch_sys_user.sql
mysql ... ry-vue < sql/lab/lab_patch_register.sql
```

**注意：**

- `lab_init.sql` 含 `DELIMITER` 触发器，请用官方 `mysql` 客户端执行；部分 GUI 对 `DELIMITER` 支持不完整。
- `lab_seed.sql` / `lab_patch_register.sql` 会把 `sys.account.registerUser` 设为 `true`（允许新生自助注册）。
- 更细的表清单与种子说明见 [`sql/lab/README.md`](sql/lab/README.md)。

### 3.3 种子账号（密码均为 `admin123`）

| 账号 | 身份 | 用途 |
|------|------|------|
| `admin` | 塔员 | 后台管理 / 塔员接口联调 |
| `ry` | 新生 | 新生登录联调 |
| `qt_member` | 塔员 | 预约/借书/服装种子数据 |
| `qt_fresh` | 新生 | 报名/面试结果种子数据 |

## 4. 修改后端配置

配置文件位置：

- [`ruoyi-admin/src/main/resources/application.yml`](ruoyi-admin/src/main/resources/application.yml)
- [`ruoyi-admin/src/main/resources/application-druid.yml`](ruoyi-admin/src/main/resources/application-druid.yml)

当前仓库里默认指向内网 IP（示例环境），**部署前必须改成你的实际地址**。

### 4.1 MySQL（`application-druid.yml`）

```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://127.0.0.1:3306/ry-vue?useUnicode=true&characterEncoding=UTF-8&connectionCollation=utf8mb4_general_ci&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8
        username: root
        password: password   # 与实际 MySQL 密码一致
```

### 4.2 Redis 与上传目录（`application.yml`）

```yaml
ruoyi:
  # Windows 示例
  profile: D:/ruoyi/uploadPath
  # Linux 示例
  # profile: /home/ruoyi/uploadPath

spring:
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password:           # 有密码则填写
```

部署前请创建上传目录，并保证运行用户有写权限：

```bash
# Windows（PowerShell）
New-Item -ItemType Directory -Force -Path D:\ruoyi\uploadPath

# Linux
mkdir -p /home/ruoyi/uploadPath
chmod -R 755 /home/ruoyi/uploadPath
```

业务上传子目录（运行时会自动创建或由接口写入）：

- `qt/clothing-item` 服装效果图
- `qt/payment-qr` 付款码
- `qt/payment-proof` 付款截图
- `qt/interview-photo` 证件照

### 4.3 服务端口

默认 `server.port: 8080`。若冲突，修改 `application.yml` 中的 `server.port`。

## 5. 编译与启动

在项目根目录：

```bash
# 编译（跳过测试）
mvn -pl ruoyi-admin -am clean package -DskipTests

# 前台启动（开发）
mvn -pl ruoyi-admin spring-boot:run

# 或运行打包产物
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

Linux 后台示例：

```bash
nohup java -jar ruoyi-admin/target/ruoyi-admin.jar > logs/ruoyi-admin.out 2>&1 &
```

启动成功日志中应出现 Spring Boot 启动完成，且无 Redis / 数据源连接错误。

## 6. 健康检查与联调

假设服务地址为 `http://127.0.0.1:8080`：

```bash
# 验证码（匿名）
curl -s "http://127.0.0.1:8080/captchaImage"

# 登录（新生入口 loginType=0；塔员用 1）
curl -s -X POST "http://127.0.0.1:8080/login" \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"qt_fresh\",\"password\":\"admin123\",\"code\":\"验证码\",\"uuid\":\"验证码uuid\",\"loginType\":\"0\"}"
```

成功响应应包含：

- `token`
- `isQuantaMember`（`0` 新生 / `1` 塔员）

其它常用匿名/业务接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/login` | 登录 |
| POST | `/register` | 新生注册（需开启注册开关） |
| GET | `/captchaImage` | 验证码 |
| GET | `/getInfo` | 登录后用户信息（需 Bearer Token） |

Swagger（若开启）：`http://127.0.0.1:8080/swagger-ui.html`  
Druid 监控：`http://127.0.0.1:8080/druid/`（默认账号见 `application-druid.yml`）

## 7. 模块与产物说明

| 模块 | 作用 |
|------|------|
| `ruoyi-admin` | 启动入口，打出可运行 jar |
| `ruoyi-framework` | 安全、登录注册、Redis |
| `ruoyi-system` | 系统用户/配置等 |
| `ruoyi-qt` | 实验室业务（活动、工位、图书、服装、面试、名单） |

业务表均以 `qt_` 为前缀，用户主数据仍用若依 `sys_user`（含实验室扩展字段）。

## 8. 常见问题

### 8.1 启动报 Unknown column `is_quanta_member` / `member_no`

未执行实验室扩展 SQL。补跑：

```bash
mysql ... ry-vue < sql/lab/lab_patch_sys_user.sql
# 或完整
mysql ... ry-vue < sql/lab/lab_init.sql
```

### 8.2 注册提示「当前系统没有开启注册功能」

执行：

```bash
mysql ... ry-vue < sql/lab/lab_patch_register.sql
```

或在库中：

```sql
UPDATE sys_config SET config_value = 'true' WHERE config_key = 'sys.account.registerUser';
```

### 8.3 Redis 连接失败

检查 `application.yml` 中 `spring.data.redis.host/port/password`，以及 Redis 是否监听 `0.0.0.0` 或本机回环。

### 8.4 登录提示身份不符

- 新生入口必须传 `loginType: "0"`，账号 `is_quanta_member` 须为 `0`
- 塔员入口传 `loginType: "1"`，账号须为 `1`
- 塔员不能自助注册，需管理员改库或后台维护

### 8.5 服装下单 / 证件照上传失败

检查 `ruoyi.profile` 目录是否存在且可写；确认 `/common/upload` 子目录白名单含 `qt/payment-proof` 等（代码已配置）。

### 8.6 触发器创建失败

使用官方 mysql 客户端重跑 `sql/lab/lab_init.sql`，不要依赖不支持 `DELIMITER` 的部分图形化工具。
