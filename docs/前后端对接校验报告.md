## 4. 问题清单（按责任方分组）

### A. 后端/运维侧（前端改 URL 解决不了，建议后端处理）

1. **图片 URL 是 `http://` 前缀 —— 影响两端，最实质的一个**
   `ServerConfig.getUrl()`（`ruoyi-framework/.../config/ServerConfig.java:20-31`）从请求头推导域名；nginx 以 HTTP 反代后端并已设置 `X-Forwarded-Proto`，但后端未启用 forward-headers 处理，`request.getRequestURL()` 得到的 scheme 是 `http`。5 处拼 URL 全部受影响：
   - 塔服效果图 `QtClothingItemController.java:191`
   - 付款凭证 `QtClothingOrderController.java:141`
   - 证件照 `QtInterviewController.java:177`、`QtInterviewAdminController.java:202`
   - 收款码 `QtPaymentConfigController.java:194`

   后果：小程序正式版拦截非 https 图片资源（塔服效果图页 `shirt-order.vue:7` 直接挂）；管理端 https 页面引用 http 图片属混合内容。
   **修复（后端一行配置）**：`application.yml` 增加 `server.forward-headers-strategy: framework`（或固定使用环境变量注入的域名）。修复后这些 URL 全部变 `https://www.quantacenter.com/profile/...`，nginx `/profile/` 反代可达，两端前端无需任何改动。
2. **招新整点登录限流可能误伤**：`/login` 20 次/60s，`LimitType.USER` 对未登录请求回退 IP 分桶（`RateLimiterAspect.java:96-97`）。校园网/实验室共享公网出口时，新生集中登录会撞同一 IP 桶。建议：调高 `/login` 计数（如 100/60s）或对登录改为按用户名分桶。
3. **CORS 未暴露 `Content-Disposition`**（`ResourcesConfig.java:55-71` 无 `addExposedHeader`）：只影响管理端**开发模式**跨域直连时的 blob 下载文件名（生产同源无碍）。管理端文档 `Quanta-admin-web/docs/backend-integration-open-items.md:43-47` 已提出此诉求，后端加一行即可闭环。
4. **已知遗留**（文档 §9 自述，与本轮校验结论一致）：
   - `/qt/materials/{id}` 资料表为空时 500（既有 NPE，管理端资料页会碰到）；
   - Swagger 生产仍 permitAll（`application.yml:137`、`SecurityConfig.java:107`），建议上线前关；
   - 线上验证码处于关闭状态（`initdb/07_disable_captcha.sql`），恢复前小程序登录页需先补验证码 UI（见 B4）；
   - 根目录 `docker-compose.yml:26-42` 的 redis 未同步 maxmemory/淘汰策略/密码（仅影响本地开发栈，线上用的是 `deploy/aliyun/docker-compose.yml`）。

### B. 前端同学侧（不需要改 URL，改功能/体验）

1. **小程序投递链路接后端**（主体工作，见 `docs/简历投递数据打通待办.md`）：`submit.vue` 的 TODO 替换为 `POST /qt/interview/apply`，进度页改读 `GET /qt/interview/my` / `myResults`；证件照用 `uni.uploadFile` 先传 `/common/upload`（subDir 按后端档位白名单）再随表单提交路径。
2. **上传与提交体验**：证件照建议 `uni.compressImage({ quality: 80 })` 后再传（后端图片档 5MB + 单边 ≤4096px 校验，新生手机原图容易撞线）；提交按钮防重 + loading；失败把后端返回的 `msg` 原样展示（后端已有 10 次/60s 限流与 5 秒防重复提交，靠 msg 才能解释「为什么被拒」）。
3. **请求超时**：`src/utils/request.ts:40` timeout 5000ms，压测 P99 已到 2.7s，高峰期偏紧，建议 8–10s。
4. **验证码**：一旦后端恢复验证码（A4），小程序登录页没有验证码 UI 会直接登录失败，届时必须补；管理端已适配无需动。
5. **图片展示兜底（可选）**：`effectImageUrl` 目前原样渲染。若 A1 修复上线则无需处理；若希望前端更健壮，可在渲染前把 `http://` 替换为 `https://`（同路径经 nginx 可达）。
6. **运维配合**：微信公众平台「开发管理 → 服务器域名」把 `https://www.quantacenter.com` 配入 request 合法域名（后续启用上传时再配 uploadFile 合法域名）。
