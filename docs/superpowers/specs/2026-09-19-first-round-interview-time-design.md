# Web 管理端一面预约时间设计

## 目标

在 Web 后台招新管理中，为每位候选人设置统一的一面面试时间。候选人的第一、第二志愿共用同一个时间；二面不做预约时间功能。

## 界面

- 仅在“一面”标签页打开“阅览简历”时显示面试时间区域。
- 提供两个单选项：
  - 2026 年 9 月 22 日 18:30–22:30
  - 2026 年 9 月 23 日 18:30–22:30
- 已有预约时间时自动选中对应选项。
- 单独提供“保存面试时间”按钮，并显示提交中的禁用状态。
- 一面表格新增“面试时间”列，显示完整日期与时间段；未预约时显示“待安排”。
- 二面弹窗和二面表格保持不变。

## 数据与接口约定

面试时间属于候选人的一面申请，不区分志愿部门。

保存接口约定：

```text
PUT /qt/interview/admin/applications/{applicationId}/rounds/1/interview-time
```

请求体：

```json
{
  "interviewTime": "2026-09-22 18:30:00"
}
```

列表或详情响应可通过 `interviewTime`、`firstRoundInterviewTime`，或一面状态中的 `interviewTime` 返回已有预约时间。前端统一归一化为 `firstRoundInterviewTime`。

## 交互与错误处理

- 未选择时间时不允许保存，并提示用户先选择时间。
- 保存成功后关闭弹窗并刷新一面列表。
- 保存失败时优先展示后端返回的错误信息；没有明确错误信息时提示“面试时间保存失败，请稍后重试”。
- 不使用本地缓存伪造保存结果，后端接口未实现时保持原数据不变。

## 测试

- API 层：验证接口地址、请求方法和请求体。
- 简历弹窗：验证仅一面显示、两个选项、已有值回显及保存事件。
- 候选人表格：验证一面时间展示、未预约状态和二面不显示该列。
- 页面联动：验证保存成功后刷新列表，失败时保留弹窗和选择内容。
