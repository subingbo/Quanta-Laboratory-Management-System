# 新生报名证件照上传区优化设计

## 目标

把新生报名表中的原生文件选择框改造成符合 Quanta 门户风格的证件照上传卡片，解决控件粗糙、预览破损文字外露和信息层级松散的问题。

## 视觉方案

- 整体为浅色横向卡片，使用现有橙色强调、细边框、圆角和轻阴影。
- 左侧为固定 3:4 的证件照预览框；有有效图片时完整裁切展示，无图片或加载失败时显示简洁的头像占位图标与“等待上传”。
- 右侧依次显示标题、用途说明、格式与 5MB 限制、选中文件名和主操作按钮。
- 隐藏浏览器原生文件输入，通过语义化 `label` 按钮触发选择，保留键盘访问能力。
- 选择新文件后即时更新预览和文件名；不改变现有 FormData 字段 `photoFile`。

## 交互与校验

- 仅接受 JPEG、PNG、WebP。
- 前端选择时校验 5MB 上限；不合规文件不进入表单，并显示就地错误提示。
- 服务端已有照片继续显示；远程图片加载失败时回退占位状态，不展示破损图片图标或 alt 文本。
- 重新选择按钮允许替换当前照片。
- 不新增依赖，不改变报名提交、草稿和真实后端接口。

## 响应式

- 桌面端使用“预览 + 说明与操作”双列布局。
- 700px 以下改为上下布局，按钮保持易点击，文字不溢出。

## 验收标准

- 原生文件选择框不再直接显示。
- 空状态、有效预览、远程图片加载失败三种状态均视觉完整。
- 文件名、格式和大小提示清晰。
- 非图片和超过 5MB 的文件被前端拒绝。
- 报名表原有提交与草稿行为不变。
- 相关组件测试、全量测试、Lint、构建和浏览器视觉检查通过。
