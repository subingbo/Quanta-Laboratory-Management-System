# Web 端入口、弹窗与报名校验设计

## 目标

- 将“返回选择身份”从后台内部顶栏移动到管理端登录页。
- 用项目自有组件替换新生报名页样式失效的 Element Plus 消息弹窗。
- 所有报名必填项完整后才允许提交。
- 兼容真实后端 `memberDepartment` 字段，恢复一面、二面编辑面评入口。

## 交互设计

- 管理端登录页在右侧表单区左上方显示“返回选择身份”，点击进入 `/`；后台登录后的顶栏不再显示该按钮。
- 新建 `PortalNoticeDialog`：固定居中的白色卡片、暗色遮罩、成功/错误图标、标题、说明和“知道了”按钮，支持键盘 Escape 与无障碍对话框属性。
- 新生报名点击提交时主动校验：姓名、性别、班级、两个不同志愿、证件照、PDF 简历、自我介绍、编程经验选项、对 Quanta 的了解必填；选择“有编程经验”时编程经历说明必填。
- 校验失败时不触发提交事件，字段显示红色状态，并通过统一提示框列出需要完善的内容。
- 部门字段依次兼容 `deptCode`、`dept.deptCode`、`memberDepartmentCode`、`memberDepartment`；中文部门名转换为业务代码。

## 范围

只修改 `Quanta-admin-web` 和测试/说明文档，不修改后端、数据库或 UniApp。
