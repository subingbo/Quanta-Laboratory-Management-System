# Web 新生端与塔员端 H5 适配设计

## 目标与范围

- 对 `Quanta-admin-web` 中的新生端、塔员端进行完整移动端适配。
- 重点覆盖 375～430px 手机视口，同时保持现有桌面端视觉与功能不回退。
- 不修改后台管理端，不修改后端接口、数据结构、权限和业务流程。

## 设计方案

采用现有组件内渐进式响应布局，不复制移动端页面：

- 公共门户头部在窄屏下缩减品牌区，并将导航改为适合触屏的横向导航或紧凑菜单。
- 双栏与多栏卡片在移动端切换为单列，控制留白、字号和点击区域。
- 新生报名表、文件上传、进度卡片、活动卡片按窄屏重新排列，主要操作按钮保持清晰可点击。
- 塔员首页、成员目录、资料、服务、招新与账号页面在移动端采用单列；无法合理压缩的数据区域允许局部横向滚动。
- 对话框限制为视口宽度并支持内容滚动，避免按钮和底部内容被裁切。
- 使用统一断点和公共变量，减少页面间重复规则。

## 兼容与验证

- 保留现有路由、接口调用、状态管理和业务逻辑。
- 以 375、390、430px 手机尺寸及常见桌面尺寸进行页面检查。
- 执行现有单元测试、代码检查和生产构建。
- 重点验证登录、导航、报名填写与上传、进度查看、活动、账号安全以及塔员各入口。
