# 移除后台一面预约时间功能设计

## 目标

从 Web 后台招新管理中完整移除一面预约时间功能，不保留隐藏入口、废弃请求或无效数据字段。

## 范围

- 删除一面候选人列表中的“面试时间”列。
- 删除“阅览简历”弹窗中的时间单选项和“保存面试时间”按钮。
- 删除页面层保存状态、保存事件和成功/失败提示。
- 删除 `PUT /qt/interview/admin/applications/{applicationId}/rounds/1/interview-time` 前端请求方法。
- 删除仅为该功能存在的数据归一化、样式和测试。
- 删除旧的一面预约时间设计与实施计划，避免文档继续描述已移除功能。

## 保留内容

- 简历阅览、PDF 预览/下载、一面面评、Pass/Out、二面评分与邮件通知逻辑保持不变。
- 新生端由后端返回的面试进度展示不属于后台预约功能，保持不变。

## 验证

- 招新管理一面、二面列表均不显示“面试时间”列。
- 简历弹窗不显示预约控件，也不会触发预约接口。
- 招新相关单元测试、完整测试、构建与代码检查通过。
