# Web 品牌标识文字禁选设计

## 目标

让 Web 端明确属于 Logo/品牌标识的文字不可被鼠标或触摸选中，减少误选和拖拽，同时不影响正文、表单、用户名及普通页面标题的复制。

## 范围

- 统一入口页 `.entry-page__brand`。
- 新生端与塔员端顶部 `.portal-header__brand`。
- 新生/塔员登录页 `.portal-login__brand`。
- 管理端登录页 `.login-page__brand` 与 `.login-card__mobile-brand`。
- 管理后台侧栏 `.app-sidebar__brand`。
- Logo 图片同步禁止浏览器原生拖拽。

## 实现

在对应现有样式文件的品牌容器上添加 `user-select: none`，并在品牌图片上添加 `-webkit-user-drag: none`。不增加全局禁选规则，不修改 DOM、跳转链接、键盘焦点或点击行为。

## 验证

- 入口、两类门户、两类登录页和管理侧栏的品牌文字不可选中。
- 页面正文和表单文字仍可正常选择。
- Logo 链接仍可点击，键盘焦点保持正常。
