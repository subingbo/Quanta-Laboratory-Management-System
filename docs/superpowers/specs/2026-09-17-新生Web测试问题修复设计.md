# 新生 Web 测试问题修复设计

## 范围

仅修改 Web 新生端及共用路由守卫，不做后端联调，不修改塔员业务页面和管理页面。

## 修复内容

1. 注册提交沿用请求中锁，并增加短时间点击防抖；邮箱验证码继续使用 60 秒重发节流。
2. 报名页不直接展示后端或 Java 内部错误，统一转换为明确中文提示，并通过 Element Plus 弹窗展示保存、提交成功和提交失败结果。
3. 新生报名性别只保留“男”和“女”。历史数据中的未知值读取时回落为空，要求重新选择。
4. 证件照仅允许 JPG/JPEG、PNG；移除 WebP 的选择提示与校验支持。
5. 报名提交成功后刷新进度并自动切换到“查看进度”。即使进度刷新失败，报名成功状态不回滚，并在进度页提示稍后重试。
6. 草稿文本继续保存到 localStorage；证件照文件单独保存到 IndexedDB，加载草稿时恢复为 File 和本地预览，提交成功或清除草稿时同步删除。
7. 当前密码、新密码、确认新密码三个输入框都使用统一的眼睛按钮切换明文与密文。
8. 路由守卫检测到用户访问不同身份的登录入口时，清理旧 Token、用户资料和动态权限路由，停留在目标登录页；访问同身份登录页仍自动回对应首页。

## 测试

- 注册重复点击只产生一次请求。
- 报名错误不会显示内部异常文本，保存与提交使用弹窗。
- 性别只有两个选项，WebP 被拒绝。
- 草稿证件照可保存、恢复和在提交成功后清除。
- 提交成功切换到查看进度。
- 三个密码框均可切换可见性。
- 塔员登录态进入新生入口时清理旧会话并停留在新生登录页。
- 运行 Web 全量测试、Lint 和生产构建。
