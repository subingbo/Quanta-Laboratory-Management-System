# Web 塔服收款与账号安全修复设计

## 范围

仅修改 `Quanta-admin-web`：修复后台塔服订购确认收款弹窗样式，并调整塔员端账号安全密码卡片。不修改接口、请求参数、权限规则或后端代码。

## 设计

- 在 Web 入口补充 Element Plus `message-box` 样式，使程序化确认弹窗恢复组件原有布局、遮罩和按钮样式。
- 塔员端单卡片账号安全页面将密码卡片水平居中；新生端密码与邮箱双卡片布局保持不变。
- 隐藏浏览器对密码输入框自动生成的原生显示按钮，仅保留页面最右侧已有的自定义眼睛按钮。

## 验证

- 单元测试覆盖确认弹窗样式入口、塔员端居中规则和原生密码按钮隐藏规则。
- 运行相关测试、代码检查和生产构建。
