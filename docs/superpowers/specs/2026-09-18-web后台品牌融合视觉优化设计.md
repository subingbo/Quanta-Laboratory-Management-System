# Web 后台品牌融合视觉优化设计

## 目标

在不改变接口、权限和业务逻辑的前提下，让 Quanta 后台管理端与新生端、塔员端形成统一的品牌视觉，并完成浏览器图标与塔员端招新表格调整。

## 视觉方向

采用“品牌融合”方案：以 `#202124`、白色和 Quanta 橙 `#ff6700` 为核心色。后台保留适合长时间使用的清晰度，同时引入外部门户的大留白、圆角卡片、轻阴影和明确的橙色操作强调。

- 深色侧栏降低视觉噪音，当前菜单使用橙色强调。
- 顶栏保持轻量，只保留页面名称、折叠入口、返回身份入口与时间信息。
- 页面背景使用暖灰白，内容卡片使用统一圆角、边框、间距和阴影。
- 表格、筛选栏、表单、按钮、状态标签和弹窗统一交互层级。
- 不使用大面积高饱和橙色，橙色只用于品牌与关键操作。

## 改造范围

### 网站图标与品牌标识

- 将用户提供的 Quanta Logo 制作为浏览器标签图标，放入 Web 公共资源目录。
- 替换后台侧栏现有字母 `Q` 标识，保留图片原始比例和黑色底色。
- 不修改新生端、塔员端现有 Logo 布局。

### 后台公共框架

- 统一后台侧栏、顶栏、主内容区与页面背景。
- 优化侧栏菜单分组、悬停态、选中态和折叠态。
- 优化顶栏按钮、标题、时间及返回身份入口的视觉层级。
- 通过公共样式让所有后台页面同步获得新卡片、表格、表单、按钮和弹窗外观。

### 重点页面

- 控制台：强化欢迎区域和统计卡片层级，保持信息数量不变。
- 招新管理：优化页签、筛选区、表格、状态、操作按钮和弹窗，业务流程保持不变。
- 其他后台页面：继承公共视觉，不进行与本次目标无关的结构重写。

### 塔员端招新报名

- 删除表格中的“加入状态”表头及对应数据单元格。
- 保留 API 映射中的 `joinStatus` 字段，避免影响其他潜在消费者。

## 响应式与可用性

- 桌面端为主要目标，常用分辨率下保证卡片和表格完整展示。
- 窄屏沿用现有侧栏折叠机制，筛选区和操作区允许合理换行或横向滚动。
- 交互状态不能只依赖颜色，继续保留文字标签与禁用状态。
- 不改变路由、权限标识、请求参数、状态判断和后端数据结构。

## 验证

- 更新或补充侧栏品牌标识、塔员端表格列及公共布局相关测试。
- 运行全部前端单元测试。
- 运行 ESLint 与生产构建。
- 本地启动后检查后台控制台、招新管理和塔员端招新报名，并生成关键页面效果图。

## 非目标

- 不修改后端代码、数据库和接口。
- 不重新设计新生端与塔员端已有页面。
- 不调整招新业务规则、权限或邮件状态逻辑。
