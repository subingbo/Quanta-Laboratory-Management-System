# Web 新生简历文本字数限制设计

## 目标

新生填写招新简历时，三个长文本字段统一限制为 500 字以内，避免提交超长内容，同时让用户清楚看到限制和当前输入量。

## 范围

- 自我介绍
- 编程经验描述
- 对 Quanta 的了解

## 交互设计

- 每个字段标题旁显示“500 字以内”。
- 文本框使用浏览器原生 `maxlength=500` 阻止继续输入。
- 文本框下方实时显示“当前字数 / 500”。
- 编程经验描述仍保持选填，其余字段原有必填规则不变。

## 校验与兼容

- 提交与保存草稿前复用统一的 500 字校验，防止脚本或历史草稿绕过输入框限制。
- 超长时在对应字段下显示明确错误，不调用提交接口。
- 不修改后端接口和提交字段，不影响桌面端与 H5 布局。

## 测试

- 验证三个文本框均包含 500 字限制与提示。
- 验证输入计数随内容变化。
- 验证超过 500 字时前端校验阻止提交。
