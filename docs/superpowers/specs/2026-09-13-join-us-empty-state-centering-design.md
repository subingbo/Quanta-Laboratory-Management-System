# Join Us 未投递提示卡居中设计

## 目标

新生进入 `Join Us` 的“流程”页且尚未投递简历时，保持现有提示卡的内容、尺寸、颜色和交互不变，仅调整其页面位置。

## 布局

顶部 `Join us` 标题栏以及“流程 / 投递”标签栏继续按现有布局占据页面顶部。它们下方的流程内容区使用现有 Flex 高度填满剩余可视空间；未投递提示卡在该剩余内容区内水平、垂直居中。

实现范围限定在 `Quanta-uniapp/src/pages/freshman/join-us/process.vue` 的 `.empty-state` 样式：移除固定顶部留白，改用 Flex 垂直居中。已投递流程、弹窗、简历投递页和业务状态判断均不修改。

## 兼容与验证

- 依赖现有父级 Flex 高度链，不引入固定屏幕高度计算。
- 在不同手机高度下，卡片始终相对于导航下方剩余区域居中。
- 运行 `npm test`，确认现有行为未回归。
- 使用正在运行的 `npm run dev:mp-weixin` 监听编译，确认微信小程序产物成功更新。
- 检查生成的 WXSS，确认空状态不再包含固定顶部间距，并采用垂直居中布局。
