# Web 报名文件状态与错误提示设计

## 目标

让新生明确知道证件照和 PDF 是否已经就绪，并在报名失败时优先看到后端提供的明确原因。

## 文件状态

- 证件照或 PDF 为空时，文件名旁状态点保持灰色。
- 新选择、从草稿恢复或服务器已有文件时，状态点显示绿色。
- 文件格式或大小校验失败时继续显示现有红色错误文字，不使用绿色状态误导用户。

## 提交错误

- 网络异常和超时继续显示现有的网络异常提示。
- 后端通过 `msg/message` 返回明确业务说明时，展示该说明。
- 后端没有明确说明时，保留“报名提交失败，请检查填写内容后重试”。
- 不根据 HTTP 状态自行推测业务原因。

## 测试

- 验证空文件为灰点、有效证件照和 PDF 为绿点。
- 验证明确后端消息会展示。
- 验证无明确消息时保留通用提交失败提示。
