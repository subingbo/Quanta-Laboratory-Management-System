# Web 端 PDF 简历功能设计

## 范围

只修改 `Quanta-admin-web`。不修改后端、数据库或 UniApp。

## 新生端

- 报名表增加“PDF 简历（选填）”上传卡片。
- 仅允许 PDF，最大 10 MB；显示已选文件名和校验错误，可重新选择。
- 报名提交沿用现有 multipart 接口，在 `FormData` 中追加 `resumeFile`。
- 草稿通过现有 IndexedDB 文件仓库保存 PDF，页面刷新后恢复；提交成功后清除。
- 兼容后端未来返回 `resumeAccessUrl`、`resumeUrl`、`resumeFileName`。

## 管理端

- 招新详情模型标准化 PDF 地址和文件名。
- “阅览简历”弹窗增加 PDF 简历区域。
- 有地址时提供“在线预览”和“下载 PDF”，没有地址时显示“暂无 PDF 简历”。
- 在线预览使用浏览器新标签页打开，下载通过带 `download` 文件名的链接触发。

## 接口约定

- 提交：`POST /qt/interview/apply` 的 multipart 字段 `resumeFile: File`。
- 返回：优先读取 `resumeAccessUrl`，其次读取 `resumeUrl`；文件名读取 `resumeFileName`，缺省为“姓名-学号-简历.pdf”。
- 当前后端不会保存该字段，前端只完成接口和交互准备。

## 验证

- 单元测试覆盖 PDF 类型/大小校验、FormData 字段、草稿持久化、详情映射、预览和下载入口。
- 运行 Web 全量测试、ESLint 与生产构建。
