# 新生报名截止时间提醒设计

## 目标

在 Web 新生端“填写报名”表单顶部醒目展示报名截止时间，降低新生错过报名时间或误以为保存草稿等于完成报名的风险。

## 展示内容

提醒文案固定为：

```text
报名截止时间：2026年9月21日 24:00
请尽早填写并提交，保存草稿不代表报名成功。
```

## 交互与样式

- 提醒位于报名表单内部最上方，在姓名字段之前展示。
- 使用与新生端一致的橙色强调样式，包含简洁的时钟图标、主标题和辅助说明。
- 提醒区域占据表单整行。
- 桌面端横向排列，窄屏自动换行，不引入横向滚动。
- 提醒仅用于告知，不可关闭。

## 业务边界

- 前端不根据本机时间禁用提交按钮。
- 不修改提交、保存草稿或表单校验逻辑。
- 真正的截止拦截应由后端服务器时间控制，避免用户修改设备时间绕过限制或被错误拦截。

## 测试

- 表单渲染截止日期和“保存草稿不代表报名成功”提示。
- 提醒出现在表单首个字段之前。
- 原有表单提交和校验测试保持通过。
- 全量测试、构建和代码检查通过。
