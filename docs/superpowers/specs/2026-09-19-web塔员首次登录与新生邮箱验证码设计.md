# Web 塔员首次登录与新生邮箱验证码设计

## 范围

仅修改 `Quanta-admin-web` 和 Web 门户接口清单，不修改后端与 UniApp。

## 塔员首次登录

- 登录成功后的 `redirect` 必须属于当前登录身份的路由域。
- 塔员仅接受 `/member/*`，新生仅接受 `/freshman/*`，管理端仅接受 `/admin/*`。
- `/`、其他身份路由、外部地址和异常值一律回退到当前身份首页。
- 该规则消除 Edge 恢复旧 `redirect=/` 地址后首次登录返回身份选择页的问题。

## 新生修改邮箱验证码

- 仅新生端账号安全页的修改邮箱卡片增加 6 位数字验证码。
- 发送前校验新邮箱；发送成功后进入 60 秒重发倒计时，并提示验证码 5 分钟有效。
- 修改邮箱必须同时提交 `email` 和 `emailCode`，提交期间禁用按钮。
- 页面卸载时清理倒计时。

## 前端接口契约

- `POST /system/user/profile/emailCode`，请求体 `{ email }`。
- `PUT /system/user/profile/updateEmail`，请求体 `{ email, emailCode }`。
- 两个接口登记为待后端实现/联调；真实模式失败时展示真实错误，不回退为成功。

## 验证

- 覆盖同身份跳转、根路径/跨身份回退、验证码格式、60 秒倒计时和邮箱修改请求字段。
- 运行相关测试、Lint 和生产构建。
