# Quanta 门户底部卡片完整展示设计

## 目标

新生端和塔员端页面使用浏览器整页纵向滚动。用户滚动到底部时，最后一排卡片的边框、圆角和阴影必须完整显示，不被视口或父容器裁切。

## 范围

- 仅影响 `PortalLayout` 承载的 `/freshman/*` 与 `/member/*` 页面。
- 保持顶部导航的 sticky 行为。
- 保留当前卡片尺寸、内容密度和视觉风格。
- 不修改 `/admin/*` 管理后台的独立滚动容器。

## 方案

1. 全局继续允许管理后台使用现有固定视口布局，但在门户布局激活时覆盖 `body` 的 `overflow: hidden`，恢复纵向滚动。
2. 门户根容器至少占满视口，不设置会截断子内容的固定高度。
3. 门户主内容区增加稳定的底部安全留白；桌面端不少于 64px，移动端不少于 44px。
4. 页面内容自然撑开文档高度，浏览器原生滚动条负责滚动，不创建嵌套滚动区域。

## 验收标准

- 新生首页可以滚动到页面底部。
- 最后一排卡片的下边框、圆角及阴影完整可见，并与视口底部存在留白。
- 新生报名、活动、安全页和所有塔员门户页面采用相同行为。
- 管理后台布局和滚动行为不变化。
- 相关组件测试、全量测试、Lint 和生产构建通过。
