# 新生 Web 邮箱验证码前端设计

## 范围

- 仅修改新生 Web 注册表单，不修改塔员端、管理端和后端。
- 邮件发送、Redis 五分钟有效期及服务端验证码校验由后端后续实现。

## 交互

- 邮箱下方增加 6 位数字验证码输入框和“发送验证码”按钮。
- 发送前校验邮箱格式；邮箱不合法时不启动倒计时。
- 点击发送后提示“验证码已发送，5 分钟内有效”，按钮立即置灰，并显示 60 秒倒计时；倒计时结束后恢复“重新发送”。
- 注册提交前校验验证码必须为 6 位数字，并将其作为 `emailCode` 随注册数据提交。
- 当前没有发送接口，因此前端只完成交互和请求字段预留，不宣称已完成真实邮件联调。

## 验证

- 单元测试覆盖邮箱非法、首次发送、60 秒锁定与恢复、验证码格式和注册请求字段。
- 运行 Web 全量测试、Lint 与生产构建。
