# Web 端招新面评权限简化设计

## 目标

简化一面、二面的操作逻辑，让所有能够进入后台招新页面的账号都能阅览简历、编辑面评和查看面评；将 Pass/Out 从查看面评弹窗移到列表操作栏，并暂定只有 `admin` 或 `ceo` 角色可以操作。

## 界面与权限

- 一面和二面均显示“阅览简历”“编辑面评”“查看面评”。
- 三个基础操作不再按照 `qt_mgmt`、`qt_manager` 或部门隐藏；仍要求账号能够进入招新后台。
- Pass 和 Out 是列表中的同级按钮，仅 `admin`/`ceo` 显示。
- 查看面评弹窗只展示面评，不再包含 Pass/Out。
- 二面列表同样可以重新打开完整简历。

## 数据流

- 阅览简历继续使用申请详情接口。
- 编辑面评继续按申请、轮次、部门加载和保存当前登录人的面评。
- 查看面评继续加载当前申请、轮次、部门的全部面评。
- Pass/Out 沿用结果保存接口，但后端额外校验 `admin`/`ceo`，避免绕过前端。

## 测试

- 覆盖普通后台账号在一面和二面的三个基础按钮。
- 覆盖普通账号看不到 Pass/Out、`admin`/`ceo` 可以看到。
- 覆盖查看面评弹窗不再渲染 Pass/Out。
- 覆盖后端普通账号不能保存面试结果。
