# 新生 Web 邮箱验证码前端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为新生 Web 注册表单增加 6 位邮箱验证码和 60 秒重发倒计时交互。

**Architecture:** 在现有新生注册组件内维护验证码字段和倒计时，组件卸载时清理定时器；当前不调用邮件接口，只预留 `emailCode` 注册字段并明确展示五分钟有效提示。

**Tech Stack:** Vue 3、Element Plus、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-17-新生Web邮箱验证码前端设计.md`

## Global Constraints

- 仅修改新生 Web 注册表单，不修改塔员端、管理端和后端。
- 验证码为 6 位数字，发送后按钮锁定 60 秒，页面提示有效期 5 分钟。
- 当前不调用或伪造邮件发送接口。
