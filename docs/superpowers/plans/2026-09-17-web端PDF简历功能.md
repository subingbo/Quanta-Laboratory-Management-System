# Web 端 PDF 简历功能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为新生报名增加 PDF 简历上传，并为管理端增加对应的预览与下载入口。

**Architecture:** 在现有报名 multipart 请求和 IndexedDB 草稿仓库上扩展 `resumeFile`，不新增网络端点。管理端通过标准化详情字段向弹窗提供可访问 URL，并使用浏览器原生 PDF 能力预览和下载。

**Tech Stack:** Vue 3、Element Plus、IndexedDB、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-17-web端PDF简历功能设计.md`

## Global Constraints

- 只修改 `Quanta-admin-web` 和本设计/计划文档。
- 不修改后端、数据库或 UniApp。
- PDF 为选填，格式仅 `.pdf`，大小不超过 10 MB。
- 提交字段名固定为 `resumeFile`。
