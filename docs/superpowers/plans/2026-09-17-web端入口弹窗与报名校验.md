# Web 端入口、弹窗与报名校验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正身份入口位置、统一新生端反馈弹窗、阻止不完整报名提交并恢复面评入口。

**Architecture:** 登录入口改动限制在登录页和后台顶栏；报名反馈由独立的 Portal 组件承载；表单组件负责返回结构化校验结果，页面负责展示提示；部门兼容逻辑集中到用户 Store。

**Tech Stack:** Vue 3、Pinia、Vue Router、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-17-web端入口弹窗与报名校验设计.md`

## Global Constraints

- 只修改 Web 端。
- PDF 简历必填，最大 10 MB。
- 无编程经验时不要求编程经历说明。
- 不改变后端接口字段。
