# Web 后台品牌融合视觉优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Quanta Web 增加品牌图标，删除塔员端招新报名的“加入状态”列，并将后台管理端统一为与新生端、塔员端一致的品牌融合视觉。

**Architecture:** 以现有 Vue 3 布局和 Element Plus 组件为基础，不重写页面结构。品牌资产进入 `public`，后台视觉通过公共变量、布局和组件样式统一下发，控制台与招新管理只做必要的重点精修。

**Tech Stack:** Vue 3、Vite、Element Plus、CSS、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-18-web后台品牌融合视觉优化设计.md`

## Global Constraints

- 不修改后端代码、数据库、接口、路由、权限标识和业务状态判断。
- 品牌主色为 `#ff6700`，基础深色为 `#202124`，橙色仅用于品牌与关键操作。
- 桌面端优先，窄屏保留侧栏折叠、表格横向滚动和操作区换行能力。
- 塔员端只删除“加入状态”展示列，保留 API 中的 `joinStatus` 映射。
- 不重新设计新生端和塔员端其他页面。
