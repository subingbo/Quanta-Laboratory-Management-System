# Web 品牌标识文字禁选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让所有明确的 Quanta 品牌标识文字不可选中，并禁止 Logo 图片原生拖拽，同时保留页面正文复制和品牌链接交互。

**Architecture:** 仅在现有品牌容器和其图片选择器上增加 CSS 交互属性，不改组件结构或路由行为。通过样式断言与浏览器交互验证覆盖入口、门户、登录和后台侧栏。

**Tech Stack:** Vue 3、CSS、Vitest、Playwright

**Spec:** `docs/superpowers/specs/2026-09-19-web品牌标识文字禁选设计.md`

## Global Constraints

- 只影响明确的品牌标识容器。
- 正文、表单、用户名和普通标题仍可选择。
- 品牌链接点击和键盘焦点不变。
