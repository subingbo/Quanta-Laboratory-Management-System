# 新生 Web 测试问题修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复新生 Web 注册、报名草稿、证件照、提示、进度跳转、密码可见性和跨身份入口问题。

**Architecture:** 保持现有页面结构，报名反馈统一使用 Element Plus 弹窗；文本草稿保留 localStorage，图片草稿通过独立 IndexedDB 工具保存；路由守卫只在跨身份进入登录页时清理旧会话。

**Tech Stack:** Vue 3、Vue Router、Pinia、Element Plus、IndexedDB、Vitest

**Spec:** `docs/superpowers/specs/2026-09-17-新生Web测试问题修复设计.md`

## Global Constraints

- 仅修改 Web 新生端及共用路由守卫。
- 不修改后端，不进行真实后端联调。
- 证件照仅支持 JPG/JPEG、PNG。
