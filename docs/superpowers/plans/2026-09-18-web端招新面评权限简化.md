# Web 端招新面评权限简化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 统一一面、二面的简历和面评操作，并将 Pass/Out 收敛为管理员专属列表操作。

**Architecture:** 保留现有列表、弹窗和接口，在 `CandidateTable` 统一按钮渲染，在页面容器复用现有结果弹窗，在后端结果接口增加角色校验。查看面评弹窗变为纯只读组件。

**Tech Stack:** Vue 3、Pinia、Element Plus、Vitest、Spring Boot、JUnit 5

**Spec:** `docs/superpowers/specs/2026-09-18-web端招新面评权限简化设计.md`

## Global Constraints

- 管理员暂定为 `admin` 或 `ceo`。
- 不修改其他后台模块。
- 一面、二面的基础操作保持一致。
