# Web 招新管理分页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为招新管理一面、二面列表增加无总条数上限的分页浏览，并让学号/姓名搜索覆盖全部候选人。

**Architecture:** 普通浏览直接使用现有后端 `pageNum/pageSize/total`；关键词搜索按 100 条一批读取当前轮次和部门范围的全部页面，再在浏览器中匹配学号/姓名并本地分页。分页展示封装为独立组件，表格和业务按钮保持不变。

**Tech Stack:** Vue 3 Composition API、Element Plus、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-19-web招新管理分页设计.md`

## Global Constraints

- 默认每页 10 条，可切换 10、20、50 条。
- 一面、二面分别保存页码。
- 部门筛选和关键词搜索从第一页开始。
- 不修改后端、候选人表格、权限和面试业务操作。
