# Web 塔员首次登录与新生邮箱验证码 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Edge 恢复错误 redirect 时塔员首次登录返回身份选择页的问题，并为新生修改邮箱增加验证码闭环。

**Architecture:** 在重定向工具层增加按身份校验，登录页只消费同身份目标。账号 API 增加新邮箱验证码请求并扩展更新邮箱载荷，账号安全页面复用注册页的 60 秒倒计时交互；完整 Mock 模式提供对应处理器，但真实模式绝不回退 Mock。

**Tech Stack:** Vue 3、Vue Router、Element Plus、Vitest

**Spec:** `docs/superpowers/specs/2026-09-19-web塔员首次登录与新生邮箱验证码设计.md`

## Global Constraints

- 仅修改 Web 前端与 Web 门户接口清单。
- 不修改后端和 UniApp。
- 真实环境接口失败不得伪造成功。
