# Web 报名文件状态与错误提示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为已就绪的证件照和 PDF 显示绿色状态点，并优先展示后端明确的提交错误信息。

**Architecture:** 在 `ApplicationForm.vue` 根据现有文件状态添加样式类；在招新页面复用请求层标准化后的 `error.payload` 判断后端消息，缺失时保留通用提示。

**Tech Stack:** Vue 3、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-19-web报名文件状态与错误提示设计.md`

## Global Constraints

- 文件为空灰色、文件存在绿色、校验失败显示现有红色错误。
- 后端没有明确消息时不推测原因。
- 不修改后端接口。
