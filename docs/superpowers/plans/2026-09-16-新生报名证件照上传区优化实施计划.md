# 新生报名证件照上传区优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Quanta 风格上传卡片替代新生报名表的原生证件照文件框。

**Architecture:** 在现有 `ApplicationForm` 内维护文件选择、预览失败和校验错误状态，保持 `photoFile`/`photoUrl` 数据契约不变；CSS 负责桌面横向与移动纵向布局。

**Tech Stack:** Vue 3、CSS、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-16-新生报名证件照上传区优化设计.md`

## Global Constraints

- 不改变真实后端接口和 FormData 字段。
- 只接受 JPEG、PNG、WebP，最大 5MB。
- 不新增依赖，不影响草稿和提交逻辑。
