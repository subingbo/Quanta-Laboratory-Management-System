# Web 新生简历文本字数限制 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为新生简历三个长文本字段增加 500 字提示、计数、输入限制和提交兜底校验。

**Architecture:** 在现有 `ApplicationForm.vue` 内维护统一常量与校验，不引入新依赖或改变接口字段；组件测试覆盖展示与校验行为。

**Tech Stack:** Vue 3、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-19-web新生简历文本字数限制设计.md`

## Global Constraints

- 三个长文本字段最大长度均为 500 字。
- 编程经验描述保持选填，其他必填规则不变。
- 不修改后端接口，不破坏桌面端或 H5 布局。
