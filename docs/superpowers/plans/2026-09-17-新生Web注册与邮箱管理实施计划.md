# 新生 Web 注册与邮箱管理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为新生 Web 提供真实注册、学号登录文案和登录后修改邮箱功能。

**Architecture:** 复用 `/register` 创建新生账号，服务端把学号强制映射为用户名并保存邮箱；为当前新生增加只更新邮箱的 profile 接口。前端登录页仅在 freshman audience 下显示登录/注册切换，安全页根据路由 audience 仅向新生展示邮箱卡片。

**Tech Stack:** Vue 3、Element Plus、Axios、Spring Boot 4、Spring Security、MyBatis、JUnit 5、Mockito、Vitest

**Spec:** `docs/superpowers/specs/2026-09-17-新生Web注册与邮箱管理设计.md`

## Global Constraints

- 只改变新生端；塔员和管理端 UI 不增加注册或修改邮箱。
- 学号格式为 `^20\d{9}$`，并强制作为 `username`。
- 邮箱必填、格式合法且全局唯一。
- 不使用 Mock 回退，成功提示必须等待真实后端成功。
