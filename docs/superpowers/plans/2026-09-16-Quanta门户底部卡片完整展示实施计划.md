# Quanta 门户底部卡片完整展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让新生端和塔员端使用浏览器整页纵向滚动，并在底部完整展示最后一排卡片。

**Architecture:** `PortalLayout` 挂载时给 `body` 添加门户专用类，卸载时清理；门户 CSS 只在该类存在时覆盖全局固定视口规则。主内容区继续自然撑高，并保留桌面端 64px、移动端 44px 的底部安全留白。

**Tech Stack:** Vue 3、CSS、Vitest、Vue Test Utils、Playwright CLI

**Spec:** `docs/superpowers/specs/2026-09-16-Quanta门户底部卡片完整展示设计.md`

## Global Constraints

- 只影响 `/freshman/*` 与 `/member/*`。
- 不改变 `/admin/*` 的滚动容器。
- 不缩小或裁切卡片。
- 保持顶部导航 sticky。

### Task 1: 恢复门户原生页面滚动并验证底部留白

**Files:**
- Modify: `Quanta-admin-web/src/layout/PortalLayout.vue`
- Modify: `Quanta-admin-web/src/styles/portal.css`
- Test: `Quanta-admin-web/src/layout/__tests__/PortalLayout.test.js`

**Interfaces:**
- Produces: `body.portal-scroll-active`，仅在门户布局存在期间启用。

- [ ] **Step 1: 写失败测试**

在 `PortalLayout.test.js` 增加测试：挂载后 `document.body` 包含 `portal-scroll-active`，卸载后该类被移除。

```js
it('enables document scrolling only while the portal layout is mounted', () => {
  const wrapper = mountLayout()
  expect(document.body.classList.contains('portal-scroll-active')).toBe(true)
  wrapper.unmount()
  expect(document.body.classList.contains('portal-scroll-active')).toBe(false)
})
```

- [ ] **Step 2: 运行测试并确认失败**

Run: `cd Quanta-admin-web && npm run test:run -- src/layout/__tests__/PortalLayout.test.js`

Expected: FAIL，因为布局尚未维护 `portal-scroll-active`。

- [ ] **Step 3: 实现门户滚动生命周期与安全留白**

在 `PortalLayout.vue` 中使用生命周期钩子：

```js
import { computed, onMounted, onUnmounted } from 'vue'

onMounted(() => document.body.classList.add('portal-scroll-active'))
onUnmounted(() => document.body.classList.remove('portal-scroll-active'))
```

在 `portal.css` 中增加：

```css
body.portal-scroll-active {
  overflow-x: hidden;
  overflow-y: auto;
}

.portal-layout__main {
  padding-block: 38px 64px;
}
```

移动端继续使用 `padding-block: 24px 44px`。

- [ ] **Step 4: 自动化与浏览器验证**

Run: `cd Quanta-admin-web && npm run test:run -- src/layout/__tests__/PortalLayout.test.js && npm run test:run && npm run lint && npm run build`

Expected: 所有命令通过。

Playwright 打开 `/freshman/home`，滚动到底部并断言最后一个卡片的 `boundingBox().bottom` 小于视口底部，且控制台无错误。
