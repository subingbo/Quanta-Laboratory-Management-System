# Web 管理端招新体验修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改后端的前提下修复管理端招新页面的五项交互与展示问题。

**Architecture:** 继续使用现有招新 API 标准化模型和 Element Plus 组件。筛选作为页面内纯前端派生状态实现，面评继续复用既有弹窗与保存接口，导航改动限制在布局组件。

**Tech Stack:** Vue 3、Pinia、Vue Router、Element Plus、Vitest、Vue Test Utils

**Spec:** `docs/superpowers/specs/2026-09-17-web管理端招新体验修复设计.md`

## Global Constraints

- 只修改 `Quanta-admin-web` 和本设计/计划文档。
- 不修改后端、数据库或 UniApp。
- 邮箱缺失时显示“暂无”。
- 招新筛选仅针对当前已加载列表。
- 保留工作区中已有的新生端未提交修改。
