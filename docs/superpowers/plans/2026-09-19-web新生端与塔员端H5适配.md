# Web 新生端与塔员端 H5 适配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变桌面端布局与业务逻辑的前提下，让 Web 新生端与塔员端在 375～430px 手机视口中完整、清晰且可操作。

**Architecture:** 继续复用现有 Vue 页面，通过公共门户断点和页面级媒体查询渐进适配，不建立第二套移动端页面。公共导航、容器和对话框由共享样式负责，各业务页面只处理自身网格、表单、列表与操作区。

**Tech Stack:** Vue 3、Vue Router、Element Plus、CSS Media Queries、Vitest、Vite

**Spec:** `docs/superpowers/specs/2026-09-19-web新生端与塔员端H5适配设计.md`

## Global Constraints

- 只修改 `Quanta-admin-web` 的新生端和塔员端。
- 重点覆盖 375～430px 手机视口，桌面端视觉和功能不得回退。
- 不修改后台管理端、后端接口、数据结构、权限和业务流程。
- 优先使用 CSS；只有导航可用性确实需要时才调整 Vue 模板。
