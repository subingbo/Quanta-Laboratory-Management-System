# Web 新生报名志愿下拉框优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将新生报名表的第一、第二志愿替换为符合 Quanta 视觉、支持键盘操作且兼容 H5 的自定义下拉选择器。

**Architecture:** 新增一个纯展示与交互职责的 `RecruitmentDepartmentSelect` 组件，使用 `v-model` 传递部门编码，并复用现有部门数组。报名表继续负责业务校验和提交，样式集中在招新页面样式文件中。

**Tech Stack:** Vue 3 Composition API、Vitest、Vue Test Utils、CSS

**Spec:** `docs/superpowers/specs/2026-09-19-web新生报名志愿下拉框优化设计.md`

## Global Constraints

- 仅修改 Web 新生端报名表的第一志愿、第二志愿选择控件。
- 不修改部门枚举、表单字段名、提交数据或后端接口。
- 保持桌面端双列布局，并兼容现有 H5 单列布局。
- 必须支持鼠标、键盘、点击外部关闭与 Escape 关闭。
